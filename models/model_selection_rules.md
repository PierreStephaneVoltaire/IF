# Subscription model selection

Sol coordinates every top-level user job and selects native Specialist workflows. The worker verifies authentication and the live subscription model catalog before execution; a missing model fails explicitly.

Use Luna for bounded implementation, summarization and straightforward independent work. Use Terra for independent parity, correctness and security reviews. Use Sol when a task needs coordination or synthesis across domains. Choose only a model returned by the worker's current subscription catalog; this file lists the preferred compatible models for main-node classification.

Every Specialist starts with its own context and scoped tools. Allow at most two native children at once. User work precedes Reflection, Heartbeat and summarization. Never switch to a paid API provider when subscription authentication or limits prevent execution.
